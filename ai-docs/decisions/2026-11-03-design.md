# Design decisions, 2026-11-03

- Outer driver with fresh sessions, not Stop hooks or /loop. Those lose state or expire (survey section 2).
- Score: value squared times road weight and confidence, divided by a human-minutes term. Squaring makes value dominate, per the brief's order. A test proves a hard valuable item beats an easy low one.
- When someone else owns the game's repo, state stays outside it. Only the lanes they allow are open, discovery is off, and stopping can be correct. Their feedback may arrive relayed, so `relay` counts as an answer.
- Worktree rules differ per game, so they are guards in the profile, not plugin rules.
- gamewright overlap: ludowright already owns balance and playtest design. grindwright calls it and owns neither.
